# 送料比較サービス

## 開発背景
複数の配送会社の料金を個別に調べる手間を減らし、
荷物の条件に合った配送方法を簡単に比較できるようにするため、
このサービスを開発します。

また、Java・Spring Bootを使用したWeb API開発やテストを実践し、
GitHubで公開できる成果物を完成させることを目的としています。

## サービスの目的
- 荷物の送料を簡単に比較できるサービス

## 利用者
- 荷物の発送方法を検討している人

## MVP機能
- 発送元と発送先：都道府県を選択
- サイズ：縦、横、高さの長さをcm単位で数値入力
- 重量：kg単位で数値入力
- 入力された縦、横、高さ、重量と、各配送サービスの条件をもとに、利用可能なサイズ区分をそれぞれ判定
- 料金データの基準日をREADMEまたは検索画面に記載
- 下記の発送方法を比較し、送料を安い順にならべて表示
- ヤマト運輸：宅急便
- 日本郵便：ゆうパック
- 佐川急便：飛脚宅配便
- 配送会社の外部APIは使用せず、各社の通常料金をDBに登録して比較する

## 対象外
- 冷凍便
- 海外配送
- 配送日数の比較
- 集荷料金
- 会員登録
- 履歴の保存
- 配送会社の外部APIとの連携
- 割引適用時の料金（会員割引等の割引を考慮せず、各社の通常料金を表示する）
- 補償の有無の表示
- 荷物追跡機能および追跡可否の比較
- 大型家具などの特殊配送
- 離島・一部地域の料金比較

## 9月のゴール
発送元・発送先・荷物の寸法・重量を入力すると、
利用可能な配送方法を判定し、料金の安い順に結果を返す
送料比較MVPをJava・Spring Bootで実装します。
JUnitによるテストとAPI検証例を含め、
第三者が動作を確認できる公開リポジトリとして完成させます。

## ローカルでの実行方法

### 1. コンパイル

MavenでJavaコードをコンパイルします。

```powershell
mvn clean compile
```

### 2. 実行

コンパイルしたJavaプログラムを実行します。

```powershell
java -cp target/classes com.ya1350.shipping.Main
```

以下が表示されれば正常に実行できています。

```text
Hello Shipping
```
