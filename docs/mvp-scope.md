# MVPスコープ

## この文書の目的
送料比較サービスの初期バージョンで実装する機能と、実装しない機能を明確にする。

## サービスの目的
荷物を発送したい人が、複数の配送会社の通常料金を簡単に比較できるようにする。

## 想定利用者
国内で荷物を発送する方法を検討している個人利用者。

## MVPで実装する機能
### 入力
- 発送元の都道府県
- 発送先の都道府県
- 荷物の縦の長さ（cm）
- 荷物の横の長さ（cm）
- 荷物の高さ（cm）
- 荷物の重量（kg）
### 判定・検索
- 入力された縦・横・高さから荷物の大きさを計算する
- 荷物の寸法と重量から、各配送サービスで利用可能なサイズ区分を判定する
- 発送元・発送先・サイズ区分に対応する通常料金をDBから取得する
- 利用可能な配送方法を送料が安い順に並べる
### 出力
- 配送会社名
- 配送サービス名
- サイズ区分
- 通常料金
- 料金順位

## 比較対象の配送サービス
- ヤマト運輸：宅急便
- 日本郵便：ゆうパック
- 佐川急便：飛脚宅配便

## 料金データの管理方法
- 配送会社のAPIは使用しない
- 各配送会社が公開している通常料金をDBに登録する
- 会員割引や持ち込み割引などは適用しない
- 料金データの基準日をREADMEまたは検索画面に記載する

## MVPの対象外
- 冷蔵・冷凍配送
- 海外配送
- 離島・一部地域の料金比較
- 配送日数の比較
- 集荷料金
- 会員登録・ログイン
- 検索履歴の保存
- 配送会社APIとの連携
- 会員割引や持ち込み割引などの割引料金
- 補償の有無および補償内容の比較
- 荷物追跡機能および追跡可否の比較
- 大型家具などの特殊配送

## MVPの完了条件
- 発送元・発送先・寸法・重量を入力できる
- 各配送サービスの利用可否とサイズ区分を判定できる
- DBに登録した通常料金を取得できる
- 利用可能な配送方法を料金が安い順に表示できる
- 主要な判定処理をJUnitでテストできている
- 検索APIのリクエストとレスポンスの例が記載されている
